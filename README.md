# Laravel Application Security Landing Page

An interactive, responsive landing page about **Laravel Application Security Practices Developers Should Follow**. Visitors tick through eight pre launch security checks and watch a shield fill up until it reads "Safe to ship".

## Features

- Interactive checklist with a live shield meter (progress is remembered in the browser)
- Colour palette taken from the Laravel logo: red, white and deep ink
- Responsive layout, sticky header, modern cards and a full footer
- Keyboard friendly with visible focus, and reduced motion respected
- Single file, no build step, no dependencies beyond Google Fonts

## Topics covered

Debug mode, environment secrets and the application key, policies and authorization, validation and mass assignment, rate limiting, API tokens, dependency audits, logging and hosting.

## Run it locally

Open `index.html` in any browser.

## Deploy on GitHub Pages

1. Push `index.html` and `README.md` to the root of your repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://<your-username>.github.io/<repository-name>/`.

## Customise

Colours live in the `:root` block at the top of the stylesheet. Checklist text lives in the `items` array at the bottom of `index.html`.
